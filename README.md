# Share the Load

A simple tool to help with calculating how much each person owes when sharing things like meals, groceries, carshares, etc. 

Requires a CSV file containing transaction amounts as input. 

All data stored locally.

## How to Run:

1. Install the latest version of Python
2. Run share_the_load.py in a terminal, e.g. by opening Command Prompt and running the following: `python3 share_the_load.py`
